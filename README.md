# Lab_python_06
Exercices traités de python sur les chaines de caratères - Cours BIN1000

Voici ci-dessous l'énoncé des exercices traités:

Exercice 1
Écrivez un programme qui demande à l'utilisateur de saisir un mot, puis affiche le nombre de voyelles (a, e, i, o, u, y) qu'il contient.
Exemple :
Entrez un mot : programmation
Le mot contient 5 voyelles.

Exercice 2
Écrivez un programme qui demande à l'utilisateur une phrase et affiche :
▪ le nombre de lettres majuscules ;
▪ le nombre de lettres minuscules.
Exemple :
Entrez une phrase : Bonjour Python
Majuscules : 2
Minuscules : 11

Exercice 3
Écrivez un programme qui demande à l'utilisateur une chaîne de caractères et affiche-la à l'envers.
Exemple :
Entrez un mot : python
Résultat : nohtyp

Exercice 4
Un palindrome est un mot qui se lit de la même façon dans les deux sens.
Écrivez un programme qui vérifie si un mot est un palindrome.
Exemple :
Entrez un mot : radar
Le mot est un palindrome.

Exercice 5
Écrivez un programme qui demande à l'utilisateur une phrase et affiche le nombre de mots qu'elle contient.
Exemple : Entrez une phrase : J'aime apprendre Python
Nombre de mots : 3

Exercice 6
Écrivez un programme qui demande à l'utilisateur un nom d'utilisateur et vérifie qu'il :
▪ contient uniquement des lettres et des chiffres ;
▪ possède au moins 5 caractères.
Affichez un message indiquant si le nom est valide ou non.

Exercice 7
Écrivez un programme qui demande une adresse courriel et vérifie qu'elle contient :
• le caractère @
• un point . après le @
Affichez un message indiquant si l'adresse semble valide.

Exercice 8
Écrivez un programme qui demande une chaîne de caractères puis affiche :
• le nombre de lettres ;
• le nombre de chiffres ;
• le nombre d'espaces.

Exercice 9
Écrivez un programme qui demande une phrase à l'utilisateur et affiche le mot le plus long.
Exemple :
Entrez une phrase : J'aime apprendre la programmation
Mot le plus long : programmation

Exercice 10
Écrivez un programme qui demande à l'utilisateur de saisir un numéro de carte de crédit, puis l'affiche de nouveau en masquant tous les caractères par des astérisques (*), à l'exception des quatre derniers caractères.
Exemple :
Entrez votre numéro de carte de crédit : 1234567812345678
Numéro masqué : ************5678

Exercice 11
Améliorez le programme de l'exercice 10 en ajoutant les validations suivantes :
• Autorisez la saisie d'un numéro de carte contenant des espaces ou des tirets (-). Avant d'effectuer le masquage, supprimez ces caractères afin de ne conserver que les chiffres.
• Vérifiez que le numéro de carte obtenu contient uniquement des chiffres.
• Vérifiez que le numéro comporte exactement 16 chiffres. Si le nombre de chiffres est inférieur ou supérieur à 16, affichez un message d'erreur approprié.

Exercice 12
Écrivez un programme qui demande à l’utilisateur un mot de passe et vérifie qu'il contient :
• au moins 8 caractères ;
• une lettre majuscule ;
• une lettre minuscule ;
• un chiffre ;
• un caractère spécial (!, @, #, $, %, etc.).
Affichez les critères respectés et ceux qui ne le sont pas.
